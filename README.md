# Restaurant-top-chef
Site officiel et application web du restaurant Top Chef : découvrez la carte gastronomique, consultez le menu en ligne, réservez votre table et suivez vos commandes en quelques clics.
🍽️ Site Vitrine — Restaurant Top Chef
Bienvenue sur le dépôt du site vitrine du restaurant Top Chef ! Ce projet est un site web statique moderne, fluide et responsive conçu pour présenter l'établissement, son savoir-faire culinaire, son menu et permettre aux clients de prendre contact facilement.

📌 À propos du projet
Le site a été développé pour offrir une présence en ligne élégante et accessible au restaurant Top Chef. Il permet aux visiteurs de découvrir l'ambiance du lieu, les spécialités du chef et de nous contacter directement via un formulaire dédié.

🌟 Fonctionnalités principales
Page d'accueil : Une présentation visuelle impactante avec un aperçu des plats signatures.

À propos / Notre Histoire : Section présentant l'équipe, la philosophie culinaire et les engagements du restaurant.

Menu & Spécialités : Présentation claire de la carte et des formules du moment          .
Page / Section Contact : Formulaire de contact dynamique, coordonnées (adresse, téléphone, email) et localisation.

Design Responsive : Adaptation optimale sur tous les supports (mobiles, tablettes et ordinateurs).

🛠️ Technologies utilisées
HTML5 : Structuration sémantique et accessible des pages web.

CSS3 : Styling, animations, typographie et gestion du design responsive (Flexbox / Grid).

JavaScript (ES6+) : Interactions utilisateurs (gestion du menu mobile, validation du formulaire de contact, animations au défilement).

🚀 Installation et Utilisation
Cloner le dépôt :

Bash
git clone https://github.com/votre-compte/restaurant-top-chef.git
Accéder au dossier :

Bash
cd restaurant-top-chef
Ouvrir le projet :

Ouvrez directement le fichier index.html dans votre navigateur web préféré.

Optionnel : Utilisez une extension de serveur local comme Live Server dans Visual Studio Code pour un rechargement automatique en temps réel.
